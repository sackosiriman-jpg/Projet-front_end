# Hotel Website - Front-End Project 
## About the project

Clos Marsealt is a fictional bed-and-breakfast website created as a front-end learning project. It introduces the guesthouse, showcases its rooms and amenities, and presents nearby places to visit. The project is for practice only: the guesthouse and its services are not real, and the contact form is a visual example.


## Technologies

- HTML5
- CSS3

## What I learned

This project helped me practise structuring a page with HTML and styling it with CSS. I learned to organize content into sections, work with images and links, and use CSS to create layouts, spacing, and hover effects.
